# Flow State

Projeto Flutter do Flow State: um app local para hábitos, tarefas, rotina, foco, treino e evolução.

## Página do projeto

A página de acompanhamento visual fica em [`docs/index.html`](docs/index.html) e pode ser publicada pelo GitHub Pages. Ela documenta a visão do produto, o radar de habilidades, a retrospectiva anual interativa e o andamento por fases.

## Desenvolvimento

O projeto é desenvolvido por fases, com commits pequenos na branch correspondente. O comando único de verificação é:

```powershell
./tooling/check.ps1
```

O workflow em `.github/workflows/quality.yml` executa a mesma verificação em runners Windows e Ubuntu.
